# Procedencia de los iconos de tecnologías

Revisión: 7 de octubre de 2026. Se compararon los SVG locales con los archivos actuales de sus catálogos o repositorios de origen. Los nombres al pasar el cursor identifican cada tecnología.

| Tecnología | Archivo local | Procedencia |
| --- | --- | --- |
| PHP, Laravel, JavaScript, Vite, MariaDB, MySQL, SQLite, Playwright, GitHub Actions, Composer, Axios, Tailwind CSS y CSS | SVG del mismo nombre | [Devicon, rama master](https://github.com/devicons/devicon/tree/master/icons); coinciden con la versión consultada |
| npm | `npm.svg` | [Devicon: npm original](https://github.com/devicons/devicon/blob/master/icons/npm/npm-original.svg); actualizado en esta revisión |
| Pusher.js | `pusher.svg` | [Simple Icons: Pusher](https://github.com/simple-icons/simple-icons/blob/develop/icons/pusher.svg); misma geometría, color de marca aplicado |
| Docker | `docker.svg` | [Kit oficial de Docker](https://www.docker.com/company/newsroom/media-resources/), símbolo Ocean Blue |
| Docker Compose | `compose.png` | [Logo publicado en el repositorio de Docker Compose](https://github.com/docker/compose/blob/main/logo.png) |
| Git | `git.svg` | [Logomark oficial de Git](https://git-scm.com/community/logos), creado por Jason Long, [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) |
| Laravel Echo | `echo.svg` | [Logo del repositorio oficial](https://github.com/laravel/echo/blob/2.x/art/logo.svg); se conserva su marca cuadrada |
| Laravel Reverb | `reverb.svg` | [Logo del repositorio oficial](https://github.com/laravel/reverb/blob/main/art/logo.svg); se conserva su marca cuadrada |
| PHPUnit | `phpunit.svg` | [Logo del sitio oficial](https://phpunit.de/img/phpunit.svg) |
| Python | `python.svg` | [Devicon: Python original](https://github.com/devicons/devicon/blob/master/icons/python/python-original.svg) |
| Microsoft SQL Server | `microsoftsqlserver.svg` | [Devicon: SQL Server original](https://github.com/devicons/devicon/blob/master/icons/microsoftsqlserver/microsoftsqlserver-original.svg) |
| Pruebas de facturación electrónica | `invoice-check.svg` | Ilustración propia de un comprobante con marca de verificación; no representa una marca comercial |
| Chromium | `chromium.png` | [Icono del código fuente de Chromium](https://github.com/chromium/chromium/blob/main/chrome/app/theme/default_100_percent/chromium/product_logo_32.png) |
| Blade | inicial B | Etiqueta neutral: no se atribuye a una marca independiente sin una fuente verificable |

Las cifras de versión (PHP 8.3+, Laravel 13, Vite 7, Tailwind CSS 4 y PHPUnit 12) provienen de la información proporcionada para los proyectos, no del icono.
