# Portafolio de Leidy Diana Principe Quispe

Sitio estático de Cinapri. El contenido principal está en HTML y se puede leer sin JavaScript. El botón ES/EN utiliza JavaScript para cambiar de idioma.

## Abrirlo en tu equipo

Necesitas Node.js instalado. No hay dependencias que instalar.

```powershell
npm run dev
```

Abre [http://127.0.0.1:8000](http://127.0.0.1:8000) en el navegador. Para detener el servidor, presiona Ctrl+C en la terminal.

- `index.html`: contenido y enlaces.
- `style.css`: diseño y adaptación a móvil.
- `script.js`: cambio de idioma, año del pie de página, interacción de iconos y animaciones.
- `img1.jpeg`: retrato.

## Iconos de tecnologías

Los SVG locales de `assets/tech` provienen de [Devicon](https://devicon.dev/) y [Simple Icons](https://simpleicons.org/) (Pusher). El símbolo de [Docker](https://www.docker.com/company/newsroom/media-resources/) procede de su kit oficial, el de [Laravel Reverb](https://github.com/laravel/reverb/blob/main/art/logo.svg) de su repositorio oficial y el de [Git](https://git-scm.com/community/logos) del sitio de Git. El logo de Git fue creado por Jason Long y se usa bajo [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Los nombres de tecnologías se muestran al pasar el cursor, enfocar o tocar cada icono. Para herramientas sin icono propio se usan iniciales.

La procedencia de cada icono está documentada en [assets/tech/SOURCES.md](assets/tech/SOURCES.md). La portada tiene escritura animada y un fondo sutil. El perfil muestra ondas suaves y las secciones aparecen gradualmente al desplazarse. Contacto escribe el título y el mensaje al entrar en pantalla. La preferencia del sistema de reducir movimiento desactiva estos efectos. En móvil, la navegación muestra la sección activa y el retrato usa un recorte más compacto.
